# X 投稿文

デフォルトでは投稿文を作るだけにし、外部アカウントへ投稿しない。投稿操作はユーザーが明示した場合だけ行う。

カードには title と OGP が表示されるため、本文でタイトルや description を繰り返さない。記事の入口となる具体的な動作と、記事が加えるずらしを 2〜3 文で書き、正規 URL を末尾に一つ置く。

```text
記事を書きました。
<具体的な場面。便利さだけで閉じず、何を見直す記事かを書く。>

https://hideshi.github.io/blog/YYYY/MM/DD/slug/
```

- 280 字以内。CJK 文字は通常 2、URL は t.co 換算で 23 と見積もる。
- ハッシュタグは原則付けない。
- 初回は末尾 `/` のある正規 URL を使い、クエリを付けない。
- 本文を読まないと解けない比喩や造語を投稿文へ置かない。
- 「誰が、何を、いつ、なぜする話か」が投稿文だけで分かるか確認する。

カードが古い、または欠けた場合:

- まず公開ページと `twitter:image` の双方が 200 を返し、JPEG が反映済みか確認する。
- 新しい共有に限り、ページ URL へ `?v=2` を付けて再取得を促せる。画像 URL にはクエリを足さない。
- 投稿済みポストのカードは差し替えられない場合がある。必要なら反映後に新しい URL で投稿し直す。
- 下書き画面のプレースホルダーだけで失敗と断定しない。
